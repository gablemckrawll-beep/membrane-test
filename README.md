# Membrane Test

Интерактивная WebGL-мембрана над шаром: упругая поверхность реагирует на движение курсора, отражает свет и создаёт настраиваемый перламутровый эффект.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

Открыть http://127.0.0.1:4173/. На Windows можно запустить `start.bat` после установки зависимостей.

## Сборка для публикации

```sh
npm run check
npm run build
```

Готовый статический сайт находится в `dist/`. Сборка включает Three.js и активную модель шара, поэтому опубликованному сайту не нужен Node.js-сервер. Настройки Vercel сохранены в `vercel.json`.

## Настройки сцены

Кнопка «Настроить» открывает параметры мембраны, волн, отражений, преломления и двух цветов перламутра. Цвета можно задать через палитру или HEX. В опубликованной версии временно доступен только дневной свет.

## Исходники и модели

- `src/main.js` — сцена Three.js, GPU-симуляция и шейдеры.
- `src/style.css` и `index.html` — интерфейс.
- `ball.glb` — активный исходный шар; `ball.blend` — его редактируемая модель.
- `logo-rounded.glb` — сохранённый логотип с выпуклой скруглённой гранью; `logo-rounded.blend` — редактируемая модель.
- `logo.svg` — исходный контур; остальные модели сохранены для экспериментов.
- `PROTOTYPE.md` — технические заметки по прототипу.
- `REFERENCE.md` — исходный разбор сайта johwska.com.

Браузер должен поддерживать WebGL2 и плавающие render targets. Скорость зависит от GPU и размера окна.
